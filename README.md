# Smart Task Manager API

REST API для управления задачами с тегами, гибкой фильтрацией и статистикой. Написан на Go с использованием PostgreSQL.

## Возможности

- Создание, чтение, обновление, удаление задач (CRUD)
- Можно добавлять несколько тегов к каждой задаче, теги создаются автоматически
- Фильтрация задач по статусу, приоритету, тегу, поиск по названию/описанию
- Сортировка списка задач по разным полям и постраничный вывод
- Получение статистики: всего задач, по статусам, просроченные и предстоящие

## Технологии

- Go (net/http)
- gorilla/mux
- PostgreSQL
- lib/pq
- godotenv

## Установка и запуск

1. Клонируйте репозиторий.
2. Установите Go и PostgreSQL.
3. Создайте базу данных и выполните `schema.sql`.
4. Скопируйте `.env.example` в `.env` и заполните параметры подключения.
5. Выполните `go get github.com/gorilla/mux`, `go get github.com/lib/pq`, `go get github.com/joho/godotenv` и `go run .`.

## API Endpoints

| Метод | Путь               | Описание                          |
|-------|--------------------|-----------------------------------|
| POST  | /tasks             | Создать задачу                    |
| GET   | /tasks             | Получить список задач (с фильтрами) |
| GET   | /tasks/{id}        | Получить задачу по ID             |
| PUT   | /tasks/{id}        | Обновить задачу                   |
| DELETE| /tasks/{id}        | Удалить задачу                    |
| POST  | /tags              | Создать тег                       |
| GET   | /tags              | Получить список тегов             |
| GET   | /stats             | Получить статистику               |
